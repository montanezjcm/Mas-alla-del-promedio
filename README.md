# Mas allá del promedio guía práctica para la aplicación del método de regresión cuantílica
Esta carpeta contiene la sintaxis del capitulo I del libro Bioestadística: Temas selectos aplicados a la salud pública.

Contiene además la base de datos llamada "GLU_SUERO.dta" con la que se puede ejecutar la sintaxis a partir de la linea 74.

Para ejecutar la sintaxis completa es necesario descargar las bases de datos directamente de la página de ensanut: https://ensanut.insp.mx 

Se adjunta un tutorial para la descarga de las bases de datos.
